## Emberbox

[![Emberbox Audio — релиз-кандидат для Linux](https://raw.githubusercontent.com/BlackSnaker/emberbox-audio/v1.0.0-rc.2/assets/updates/2026-11-20-release-candidate.png)](https://github.com/BlackSnaker/emberbox-audio)

**Emberbox Audio** — музыкальный плеер для Linux с живыми лампами, тактильными регуляторами, караоке и плавными переходами между треками. В одном интерфейсе собраны Apple Music, Spotify, Яндекс Музыка и YouTube.

[Репозиторий](https://github.com/BlackSnaker/emberbox-audio) · [Скачать релиз-кандидат](https://github.com/BlackSnaker/emberbox-audio/releases/tag/v1.0.0-rc.2) · [Обсуждения](https://github.com/BlackSnaker/emberbox-audio/discussions)

**[Emberbox Video](https://github.com/BlackSnaker/emberbox-video)** — настольный YouTube-плеер для Linux в том же стиле.
